Pravrudhi
=========

Pravrudhi is a recursive self-improvement engine for language-model systems, plus a Nyaya screening product built on
the same engine. This is the code documentation: what each package is for, how to drive the command line, which
configuration files and environment variables exist, which HTTP routes the server offers, and how to build, test and
contribute. The code reference under *API reference* is read from the docstrings in ``src/`` and
``pravrudhi_kernel/src/``.

Nothing here states a measurement. Measurements live in the ledger and the evidence documents rendered from it.
